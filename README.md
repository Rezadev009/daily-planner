# Daily Planner

A simple desktop application built with Python and Tkinter to help users organize their daily tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or undo
- Track daily progress
- Automatically save tasks
- Load saved tasks when the application starts

## Technologies

- Python
- Tkinter
- JSON

## How to Run

1. Install Python.
2. Download the project.
3. Run the main Python file.
